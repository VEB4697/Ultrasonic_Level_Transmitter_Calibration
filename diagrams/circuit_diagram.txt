1. COMPONENT LIST
=================
  - Arduino UNO (ATmega328P)
  - HC-SR04 Ultrasonic Distance Sensor
  - 5V Single-Channel Relay Module (active-LOW input)
  - Green LED + 220 ohm resistor
  - Red   LED + 220 ohm resistor
  - Water pump (5V or 12V, controlled via relay)
  - Transparent tank / container (height ~30 cm)
  - Ruler for reference measurements

4. SIGNAL FLOW & WORKING PRINCIPLE
====================================

Step 1 — Ultrasonic Measurement:
  Arduino sends a 10 µs HIGH pulse to HC-SR04 TRIG (Pin 9).
  The sensor emits an 8-cycle 40 kHz ultrasonic burst.
  ECHO pin goes HIGH for a duration proportional to round-trip time.
  Distance = (echo_duration_µs × 0.03435) cm  [at 25°C]
  Level    = TANK_HEIGHT_CM - distance

Step 2 — Moving Median Filter (N=7):
  A ring buffer of 7 distance readings is maintained.
  The median of the 7 values is used to reject spike noise.
  This is more robust than moving average for outlier rejection.

Step 3 — Gauss Elimination Calibration:
  Calibrated Level = COEFF_A0 + COEFF_A1 × raw_distance
  Coefficients are derived offline by MATLAB or Python and
  uploaded into the firmware constants COEFF_A0, COEFF_A1.

Step 4 — Pump Hysteresis Control (via Relay):
  if  level >= 22 cm  →  Relay ON  (Pin 7 = LOW)   → Pump runs
  if  level <=  8 cm  →  Relay OFF (Pin 7 = HIGH)  → Pump stops
  Hysteresis band prevents rapid on/off cycling.

Step 5 — LED Indicators:
  Pump OFF (normal)  → GREEN LED ON, RED LED OFF
  Pump ON  (HIGH)    → RED LED ON,   GREEN LED OFF

Step 6 — Serial Telemetry (115200 baud):
  Format:  DIST,<cm>,LEVEL,<cm>,PCT,<%>,RELAY,<0|1>
  Example: DIST,18.72,LEVEL,13.44,PCT,44.8,RELAY,0
  Read by: MATLAB HMI (level_calibration_gauss.m)
           Python bridge (serial_bridge.py) → Web dashboard

5. NOTES
=========
  - Relay Module: Most common 5V relay modules have active-LOW inputs.
    The firmware sets Pin 7 LOW to energise and HIGH to de-energise.
    Verify your module's input logic before connecting.
  - HC-SR04 range: 2 cm to 400 cm. Mount sensor 2–3 cm above max water level.
  - Update TANK_HEIGHT_CM in the .ino file to match your actual tank height.
  - After collecting calibration data, update COEFF_A0 and COEFF_A1.
